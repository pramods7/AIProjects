## 🌟 Overview

This project establishes the programmatic foundation required for modern SDETs and QA architects to build AI agents, interact with LLM APIs, and orchestrate automated testing pipelines using Python and CrewAI.

### Key Concepts Covered
- **Python for AI**: Modern type hinting, async patterns, and LLM API integrations.
- **Agent Basics**: Roles, Goals, Backstories, and LLM configuration with CrewAI.
- **Task Delegation**: Connecting agents with specialized tools for test planning and analysis.

## 🚀 Getting Started

### 1. Setup Virtual Environment
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install crewai langchain-community
```

### 2. Run the First Agent
```bash
python crewai/hello_crewai.py
```
